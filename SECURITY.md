# Signaler une faille de sécurité

Le suivi porte sur le site [LorR](https://lorr.corentinl5.be/) et la branche
`master` du dépôt `CorentinL5/LorR`.

1. Utilise le bouton **Report a vulnerability** dans l’onglet **Security and quality**
   s’il est disponible. [Signalement privé sur GitHub](https://github.com/CorentinL5/LorR/security/advisories/new)
2. Si GitHub ne propose pas ce bouton, envoie un message privé à Corentin
   Lallement. [Profil LinkedIn](https://www.linkedin.com/in/corentinl5/)
3. Indique la page ou la version touchée, les conditions du problème et son
   impact. Retire les secrets, les données personnelles et les liens de
   planning privés des captures et des journaux joints.

Garde le signalement privé le temps que Corentin examine le problème et
prépare un correctif. Pour les bugs ordinaires, suis le [guide de contribution](CONTRIBUTING.md).
