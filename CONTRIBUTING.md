# Contribuer à LorR

Travaille avec Corentin Lallement dans le dépôt d’origine de LorR.

1. Décris ton idée ou le problème dans une [issue GitHub](https://github.com/CorentinL5/LorR/issues/new).
2. Attends l’accord de Corentin avant de commencer. Il te donnera accès au
   dépôt si le changement est retenu.
3. Crée une branche dans ce dépôt. Suis les étapes du [README](README.md)
   pour lancer LorR en local.
4. Ouvre une pull request vers `master`. Indique ce que tu as modifié et les
   vérifications que tu as faites.

Pour un changement qui touche aux horaires, vérifie le parcours du lien
invité jusqu’au calendrier. Utilise des données fictives dans les exemples et
les captures. Garde les identifiants, les bases SQLite, les journaux et les
fichiers de configuration privés hors de Git.

Pour signaler une faille, utilise le canal privé décrit dans [SECURITY.md](SECURITY.md).
Pour republier le code ou héberger une copie de LorR, demande l’autorisation
écrite de Corentin. [Conditions d’utilisation du code](LICENSE)
